# Запуск фронтенда (клиентской части)

Для локального запуска клиентской части выполните следующие шаги:

1. **Перейдите в директорию клиента:**
   ```bash
   cd client
   ```

2. **Установите зависимости:**
   Проект использует `pnpm`. Если он не установлен, установите его командой `npm install -g pnpm`.
   ```bash
   pnpm install
   ```

3. **Запустите сервер разработки:**
   ```bash
   pnpm dev
   ```

### Требования
* **Node.js**: Рекомендуется LTS версия (v20+).
* **API**: Перед запуском клиента убедитесь, что серверная часть запущена и доступна, так как клиент ожидает работающее API.
